# ChatGPT DOM Trimmer

A lightweight Chrome extension that collapses older ChatGPT messages into text-only snippets, reducing DOM bloat and memory consumption during long conversations.

## Quick start
1. Open **chrome://extensions** in Chrome and enable **Developer mode**.
2. Click **Load unpacked** and pick the `extension/` directory.
3. Open ChatGPT (chatgpt.com or chat.openai.com) and the trimmer will automatically collapse older messages.

See `extension/README.md` for more details.
